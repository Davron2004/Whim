## How to resume (gotchas this run hit)

- **Playwright installs process signal handlers by default.** `browserLaunchOptions()` now sets `handleSIGINT/SIGTERM/SIGHUP: false`, so the server's SIGTERM drain owns shutdown. Don't remove them; the e2e SIGTERM case catches that.

- **Usage limits kill every running agent at once.** After a reset, message the SAME agents (their transcripts survive) with "resume from your worktree state" instead of dispatching fresh ones. That happened at 2026-09-15 ~01:30.

- **Runbook:** `.claude/commands/opsx/apply.md`. Ledger every dispatch and merge as it happens. Merges and regates are strictly serial in the primary tree, which must stay clean.
- **Worktree creation:** use `~/.cache/whim-launch-2026-09-14/mkwt.sh <change>-<chain>`. It creates the worktree at the staging tip, builds, and makes `node_modules` a directory of per-entry symlinks with `@whim/{contract,server}` pointing at the worktree's own workspaces. A bare `node_modules` symlink makes `@whim/contract` resolve to the PRIMARY tree and hides the chain's own edits.
- **Native builds from a worktree:** for iOS, `xcodebuild ... SKIP_BUNDLING=1 build` (run `pod install` first; restore `ios/Podfile.lock` afterwards, since it drifts). For Android, Metro can't resolve through worktree symlinks. Use a scratch Gradle `--init-script` that sets `react.bundleConfig` to a metro config with `projectRoot` set explicitly to the worktree (`getDefaultConfig(__dirname)` points at the scratch dir and silently watches the wrong tree) and `watchFolders` containing the worktree plus the primary `node_modules`, requiring `@react-native/metro-config/dist/index.js` by absolute path. Never commit either.
- **Protected config:** `scripts/gate.sh` refuses to run while `package.json` or `package-lock.json` differ from HEAD, so commit a human bootstrap first, then gate it.
- **Commit messages:** no Co-Authored-By trailer (owner rule).
- **Subagent write guard:** it blocks writing a markdown file whose name contains "report". Name contracts around it; server chain-5's contract is `handoff/admin-contract.md`.
- **Browser:** ego-browser only. Once the owner takes a task space, no agent (not even the main thread) may take it back; the classifier blocks it. Start a new space instead. The Google session for the Play account is `/u/1/`.
- **Stop hook:** the SubagentStop gate hook gates the primary tree, not the implementer's worktree, so a hook "failure" during parallel work is usually false. Verify inside the worktree.
- **Model budget:** Sonnet for builders, Opus only for planning, review and the concurrency- or security-shaped chains, with no more than two Opus agents at once.
- **Classifier and network:** the auto-mode classifier refuses `deploy/provision.sh` and `deploy/deploy.sh` (production deploy) and any outbound `curl`; the owner runs those with `!`. The `!` shell has no stdin, so `cat > file` produces an empty file; use `pbpaste > file` for secrets. `deploy.sh --site-only`, `deploy/smoke.sh`, and `gcloud compute ssh/scp` run fine from the agent.
