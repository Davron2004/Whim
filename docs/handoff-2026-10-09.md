## Gotchas learned tonight

- Never resume a subagent whose transcript is already huge (the first designer died at ~940k tokens);
  give each phase a fresh agent that reads the previous phase's committed docs.
- A history rewrite must be path-partitioned from the base, never `read-tree <historical commit>` —
  historical trees carry blobs the tip deleted.
- Parallel worktree gates collide on fixed ports — fixed for the Firestore emulator; check others before
  adding fixed-port suites.
