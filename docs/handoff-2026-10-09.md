## Gotchas learned

- **WebView floor = Chromium 91** (the API 29 image; oldest testable here). Esbuild's `es2019` target lowers syntax, not built-ins: `Object.hasOwn`, `.at`, `toSorted`, `structuredClone`… crash on 91. The `post_floor_builtin` static check now guards the SDK, runtime, fixtures and generated apps (Sonar S6653 recommends `Object.hasOwn` — keep the `own()` helper and its NOSONAR). Record as a decision entry when design-system-v1 archives.

- Never resume a subagent whose transcript is already huge — fresh agent per phase, reading committed docs.
- Fast gate ≠ full gate: Chromium suites (invariants, synthetic run, SDK motion), knip and openspec only
  run in `gate-full.sh`; run it after every merge touching `src/sdk`, `src/runtime`, `synthrun`, `build`.
- The SDK's types are part of a prompt contract: any narrowed/added export must update
  `docs/sdk-reference.md` in the same commit (`server/test/prompts.suite.ts` enforces exports).
- Never `| tail` or `2>/dev/null` a `git add`/`git commit`/`openspec validate` whose status matters.
- Since waitlist-hardening, the Firestore backend needs `WHIM_WAITLIST_FINGERPRINT_KEY` even on a laptop.
- Maestro's default session uninstalls its drivers at the end; on a real phone install them once via
  `adb` and only ever run `maestro test --no-reinstall-driver`.
- A dispatched agent that needs an approval nobody can give waits for ever (#181). Tell every child:
  one simple command per Bash call, no heredocs, no `rm -rf`, no `&`, no `sleep`, edits through
  Write/Edit. If a child's worktree stops changing, start a fresh agent in a NEW worktree.
- Device builds dirty `ios/Podfile.lock`, `project.pbxproj` and `PrivacyInfo.xcprivacy`; restore them
  before running the gate (its store-privacy check fails on the last one), and never `git stash` mid-build.
- Never `npm run android:release` with a phone attached: it installs on every device. Use
  `./gradlew :app:assembleOffline` and `adb -s <emulator> install -r -d`.
- Two chains that both need a new stub in the shared test rig (`test/native-host.tsx`) will collide:
  name the rig's owner in the chain blocks.
