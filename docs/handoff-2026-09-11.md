## Jig, honestly

Setup was the expensive part: a clean clone at `~/.cache/whim-jig/Whim` with the primary `node_modules` symlinked (the symlink needs a bare `node_modules` line in `.git/info/exclude`; `guard:metro` cannot run there), a plan file outside the repo, two `jig check` passes. The loop itself was six CLI calls and two agents for one task. The verifier passed first try, so by the measure agreed beforehand (did it catch something direct dispatch would have merged?) it did not earn its overhead on a mechanical job. What it proved is that the tool works on a foreign repo with the workspace quirk. One real lesson: a rubric that sounds precise can be wrong at the language level ("let only if reassigned" versus a bare declaration assigned once in a `try`); the builder flagged it and the clarification went to the verifier by hand, which a lowered Workflow run would not have had. Use jig for structural refactors where an independent verifier matters; do sweeps by direct dispatch.
