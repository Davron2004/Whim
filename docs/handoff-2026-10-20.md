## Gotchas learned this session (also in memory)

- **Android WebView double-scales text** unless `textZoom={100}`: about 4× at a 200% phone setting.
- **Android `configChanges`** must include `fontScale` and `uiMode`, never `density`. A static guard is in
  `scripts/release/lib/android-project.ts`. `MainActivity` handles the live font-scale change and the bar appearance of
  RN Modal dialogs.
- **A fresh install talks to production.** Device agents must set "Your own server" before any generation.
- **iOS release builds do log JS:** `log stream --level info --predicate 'subsystem == "com.facebook.react.log"'`.
- **react-native-screens on iOS:** never pop and then unmount or replace the native stack mid-animation (blank Home).
  A closing Sheet's Modal still takes Android back.
- **Each version stores its own `manifest.json`/`schema.json`.** The launch and change paths read them with the code,
  in one serial section (`StoreAccess.activeLaunch`/`activeEdit`/`activeWords`).
- **Ratchet base** is `git merge-base <staging> <chain>`, never the staging tip (#197; runbooks fixed).
- **Agents run `gate.sh` in the primary tree** when the shell cwd resets. Briefs give the absolute worktree path.
- **Big chains:** split into small sequential pieces, each with a token budget, a WIP-commit hand-over and a status file.
