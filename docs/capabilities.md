| sdk-design-system | One token module (`src/design/tokens.ts`) for every design value: light and dark roles with reserved status hues, ten named app tints, the system font; an app names its `tint` and glyph `icon` and every name resolves; one vendored icon set; the SDK kit on the system's defaults (adds `Icon`, `Stepper`, `DateInput`, `Picker`, `toast`, `Screen` title/action, keyed `List`, ring `ProgressBar`; deprecates `Heading`, `radius` and `tileColor` without removing them) with WAAPI spring motion honouring Reduce Motion, resolved through a sanitized, inert host-supplied theme under the unchanged containment contract | openspec/specs/sdk-design-system/spec.md |
| generation-contract | The shared device↔server wire contract: zod schemas for generation/rewrite/clarify requests, the SSE event stream (terminal `result` carrying an optional post-run summary), optional plan rows on the rewrite response, diagnostics envelope, wire app record (its manifest carrying the declared `tint`, `icon` and legacy `tileColor`), and usage — zod-only, TS-source-only, Metro-safe, except one declared type-only exception for the dev-log envelope shared with `host-observability` | openspec/specs/generation-contract/spec.md |

| server-deployment | Production on Cloud Run (`whim-server` gen2 with Chromium's sandbox, at most one instance; `whim-site` Caddy pages host; domain mappings and managed TLS), the self-contained build tree, boot preflight and self-test with a same-options Chromium launch retry, the pinned non-root image, graceful drain, secrets as Cloud Run secret refs, association files and the consent-matched privacy pages, the no-spend load test, Cloud Run log-based alerts applied on every plain deploy, the Cloud Run smoke ending every deploy (one live clarify from a fixed smoke device), the off-production Firestore admission load test, the retired VM artifacts kept checked, and the runbook (`docs/deploy.md`) | openspec/specs/server-deployment/spec.md |
