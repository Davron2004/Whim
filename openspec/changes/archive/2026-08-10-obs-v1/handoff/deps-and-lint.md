## The lint tripwire (two `no-restricted-syntax` entries in `.eslintrc.js`)

Selectors, verbatim:

```
CatchClause[body.body.length=0]

CatchClause[param=null][body.body.length>0]:not(:has(ThrowStatement)):not(:has(CallExpression[callee.object.name="log"])):not(:has(CallExpression[callee.name=/^log[A-Z]/]))
```

Messages (both begin "No error is swallowed silently:"): the first names the empty-catch case;
the second the bindingless-no-throw-no-log case. Both name the ways to satisfy the rule.

**Ways a catch satisfies the rule** (what the selectors encode):

1. Rethrow (`ThrowStatement` anywhere in the block, nested callbacks count — accepted false
   negative, design D9).
2. Call a member of an object literally named `log` — **therefore chain-B MUST export the seam
   logger under the binding name `log`, used as `log.<level>(…)` at call sites.** A differently
   named import will not satisfy the rule.
3. Call a `log`-prefixed helper (`/^log[A-Z]/`, e.g. `logGenError(...)`) — a wrapper that itself
   logs through the seam.
4. Bind the error and handle it (`catch (e) { … }` with a non-empty body) — handling is outside
   the selectors by design.
5. A documented inline disable (below).
