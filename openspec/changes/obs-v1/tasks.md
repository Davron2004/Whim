# Tasks: obs-v1

Groups A–H map one-to-one onto the chains in `chains.md`. Every new suite joins an **existing**
runner (design D10) — `src/host/launcher/test/acceptance.ts` for device suites,
`server/test/run.mjs` for server suites. No agent adds an npm script: `package.json` is protected
and the one new script ships in group A's human-applied patch.

Every user-visible string comes from `src/host/launcher/copy.ts`; no screen invents copy.

## B. The logging seam

- [ ] B1 Create `src/host/logging/` with the channel registry: the declared channel constants
  replacing the `[whim:gen]` / `[whim]` / `[whim:page]` literals (`research.md` §3), plus the
  channel the screen boundary reports on and the channel the sink reports its own failures on. A
  call site imports a constant; it never writes a literal.
- [ ] B2 Build the logger on `react-native-logs@5.6.0`: ordered severity levels, a per-channel
  threshold, and a structured payload (named fields) alongside the message. Delta:
  `host-observability` §"One logging seam; `console.*` is not a device log surface".
- [ ] B3 Add the redaction step: any field whose name is in the sensitive set (prompt text,
  generated source, device id, API key) has its value replaced with a fixed marker **before** the
  record reaches any transport, so no sink can disagree with another (design D3). Delta:
  §"Sensitive fields are structurally unloggable on the device".
- [ ] B4 Add the ring-buffer transport: fixed capacity, oldest-evicted, never persisted, exposing a
  stable snapshot read that cannot observe a partially-written record. Delta: §"Every log record is
  a structured event held in a bounded ring buffer".
- [ ] B5 Add the batching HTTP sink transport: bounded by record count **and** flush interval,
  drops oldest pending rather than growing, off unless the explicit flag is set (design D5),
  destination = the server address the device already persists (design D4). A delivery failure is
  recorded in the ring buffer and does **not** recurse into another attempt for that record, does
  not throw into the caller, and never surfaces to the user. Delta: §"Batched delivery to the dev
  sink is best-effort and never affects the app".
- [ ] B6 Add `contract/src/dev-log.ts`: the record and batch **types** and the sink route's path,
  with **no** runtime export (design D6). Deltas: `generation-contract` §"The dev log envelope is a
  type-only contract module" + the modified §"Shared wire-contract package".
- [ ] B7 Add `src/host/logging/test/logging.suite.ts`, registered in
  `src/host/launcher/test/acceptance.ts`: level ordering and threshold filtering; channel
  constants are the only channel source; redaction of each sensitive field name and that both
  readers see the redacted value; ring-buffer capacity, eviction order and snapshot stability;
  sink batching, the off-by-default rule, and that an unreachable sink produces a buffered record
  and no throw and no second attempt.
