# Contract: icons (chain-2)

Pure TS modules under `src/design/icons/`, no RN/DOM import, safe for the SDK bundle, the shell (Metro),
the server and Node suites. Import from the submodule files directly (there is no barrel).

## `names.ts`

```ts
export const GLYPH_GROUPS: { readonly 'Time': readonly ['timer', …]; …13 groups as system.md §3.1 };
export type GlyphName = /* union of the 147 glyphs */;
export const GLYPH_NAMES: readonly GlyphName[];            // 147, group order of system.md
export const CHROME_NAMES: readonly ['chevron-left', 'chevron-right', 'chevron-down', 'arrow-left',
  'arrow-up', 'x', 'check', 'plus', 'minus', 'ellipsis', 'settings', 'search', 'copy', 'share',
  'external-link', 'info', 'circle-alert', 'triangle-alert', 'circle-check'];
export type ChromeName = (typeof CHROME_NAMES)[number];
export const FALLBACK_ICON = 'circle';
export type IconName = GlyphName | ChromeName | typeof FALLBACK_ICON;
export const ICON_NAMES: readonly IconName[];              // glyphs, then chrome, then 'circle' (167)
export const ICON_ALIASES: Readonly<Record<string, GlyphName | ChromeName>>;
export const ICON_KEYWORDS: ReadonlyArray<readonly [GlyphName, readonly string[]]>;

export type IconDiagnosticKind = 'icon_alias' | 'icon_keyword' | 'icon_fallback';
export interface IconDiagnostic {
  kind: IconDiagnosticKind;
  requested: string;   // the name exactly as declared
  resolved: IconName;  // the name that is drawn
  message: string;     // one plain sentence quoting `requested` and `resolved`
}
export interface IconResolution<N extends IconName = IconName> {
  name: N;
  diagnostic?: IconDiagnostic;   // absent iff `requested` is exactly a set name
}

export function resolveIcon(name: string, appName?: string): IconResolution;
export function resolveGlyph(name: string, appName?: string): IconResolution<GlyphName | 'circle'>;
```

Resolution order (both resolvers; never throw, never return an empty name):

1. `name.trim().toLowerCase()` is in the set → that name (`icon_alias` diagnostic only if trimming or
   case changed it).
2. `ICON_ALIASES[normalized]` whose target is in the set → target, `icon_alias`.
3. Keyword table on the name's words, then on `appName`'s words → glyph, `icon_keyword`.
4. Otherwise `'circle'`, `icon_fallback`.

- `resolveIcon` (SDK `Icon name`): set = glyph + chrome. `resolveGlyph` (tiles, `defineApp icon`):
  set = glyph only, so a chrome name or an alias into the chrome set falls through to keywords/`circle`.
- Words: split on camelCase humps and on every non-`[a-z0-9]` run, lower-cased. A keyword matches a
  whole word, or that word plus a trailing `s`; `stem*` matches by prefix; a hyphenated keyword
  (`pour-over`) matches consecutive words. The earliest matching word in the text wins; table order
  breaks ties at one position.
- Deterministic: same inputs → deep-equal results. Diagnostics are warnings for the build/eval; no name
  fails a build. Alias lookup is own-property only (`__proto__`, `constructor` fall back to `circle`).

## `paths.ts` (generated by `node scripts/vendor-icons.mjs`; never hand-edit)

```ts
export const ICON_VIEWBOX = 24;
export const ICON_PATHS: Readonly<Record<IconName, string>>;  // every IconName, typed exhaustive
```

Path data format: one SVG path `d` string per icon on a `0 0 24 24` viewBox, all of Lucide's shapes
(`circle`, `rect`, `line`, `polyline`, `polygon`, `path`) joined as subpaths, each starting with an
absolute `M`. Draw with `fill="none" stroke="currentColor" stroke-linecap="round"
stroke-linejoin="round"` and the stroke width of system.md §3.1 (1.5 at 16–20, 1.75 at 24–28; tile
glyphs 2). Works unchanged as `<path d>` in inline SVG and `<Path d>` in `react-native-svg`.
Source: lucide-static@0.460.0 markup as inlined in `docs/design/mockups/index.html` (ISC; notice in
`src/design/icons/LICENSE`, which must ship with the set).

## `ember.ts`

```ts
export const EMBER_VIEWBOX = 48;
export const EMBER_PATH: string;  // closed flame silhouette on a 0 0 48 48 viewBox, identical to the mockup's
```

Fill and states (working gradient, stuck 35%, out = 1.5 pt `text-2` outline: stroke width
`1.5 * 48 / size` in viewBox units) are the consumer's job per system.md §3.3.

## `squircle.ts`

```ts
export const SQUIRCLE_CORNER = 0.225;           // corner radius as a fraction of the side
export function squirclePath(size: number): string;
```

Closed absolute path (`M`, `L`, `C`, `A`, `Z`) of a `size × size` plate with its top-left at the
origin; touches all four edges; each corner is a circular arc of radius `0.225 × size` centred
`(r, r)` in from the corner, eased into the edges by two cubics (60% smoothing, iOS continuous corner).
Scales linearly with `size`. Use a `0 0 size size` viewBox, or draw at one size and scale.
