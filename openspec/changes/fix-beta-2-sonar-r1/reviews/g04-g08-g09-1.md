# VERIFY g04 / g08 / g09 (Opus high, round 1)

## Prescribed S2699 helper design (both g08 and g09)
File-local helpers in storage acceptance.ts's record-not-throw shape (acceptance.ts:37-53, which Sonar already passes): each helper runs `nodeAssert.ok` / `nodeAssert.deepStrictEqual` inside a try; a non-AssertionError is rethrown; an AssertionError goes to `h.fail(msg)`; on success the real arguments are forwarded to `h.ok(cond, msg)` / `h.eq(a, b, msg)` (keeps the pass count, reports every failure, never throws, no edits outside the allowlists). No `h.ok(true, ...)` dummies. Do not build the inspect message eagerly twice on passing calls (OOM memory: bounded messages). checks/test/harness.ts is not suitable (its assert throws; cross-file following unproven).
